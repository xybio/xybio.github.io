我把常见生信任务拆成三类：脚本生成、报错排查、结果解释，并为每一类维护一套提示词模板。

模板结构

  1. 任务目标：一句话说明要解决什么。
  2. 输入上下文：数据格式、环境、依赖、已有代码。
  3. 输出约束：希望得到的文件、函数或分析结论格式。
  4. 验证标准：如何判断输出可以直接用。

使用原则

  • 让模型先澄清不确定项，再生成方案。
  • 每次输出都要求给出可验证步骤。
  • 对关键结论做人工复核，避免过度依赖自动回答。
